# Vetor0
Manipulação de Vetores na Prática

Na última atividade de Lógica de Programação e Algoritmos (LOPAL), a gente teve que colocar a mão na massa com vetores. A ideia principal era aprender a guardar e mexer com os dados direto na memória, mas com um detalhe importante: tínhamos que fazer tudo na raça, usando lógica pura, sem poder rodar aquelas funções prontas que os arrays já têm.

O trabalho foi dividido em três partes:

No primeiro exercício, o desafio era criar um programa para puxar a idade de 8 pessoas e salvar tudo num vetor. Depois que o código recebia todos os números, ele somava e mostrava a média de idade do pessoal.
Depois, passamos para um filtro de dados. O programa precisava ler a idade de 7 pessoas e, logo em seguida, fazer uma varredura nesse vetor para descobrir e mostrar em quais posições estavam guardadas as idades de quem tinha mais de 25 anos.
